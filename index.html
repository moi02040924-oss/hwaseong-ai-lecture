나를 발견하기 — 6가지 중 골라서

여섯 가지가 있지만 딱 두 개만 고르시면 됩니다. 뷔페처럼 마음에 드는 것만 드세요 — 어떤 걸 고를지 모르겠으면 ①번과 ⑥번입니다. 이 둘만 해도 '나를 소개하는 한 장'이 완성됩니다.

① 대표 실습 · 꼭 해보세요

강점 발견 — 경력에서 강점 3가지

워크시트에 적은 경력을 넣으면, 나만의 강점 3가지를 뽑아줍니다.

📋 붙여넣을 프롬프트

나는 (나이)대이고, ( 경력·해온 일 )을 해왔어. 내가 특히 뿌듯했던 일은 ( 1~3가지 )이야. 이걸 바탕으로 나의 강점 3가지를 쉬운 말로 정리하고, 각 강점마다 그렇게 본 이유를 한 줄씩 붙여줘. 표로 보여줘.

  • 나온 강점 3개를 종이 '강점 카드'에 그대로 옮겨 적기 — 손으로 써야 내 것이 됩니다
  • 어색한 강점은 "이건 왜 그렇게 봤어?"라고 되물어 확인
  • 🎤 타자가 힘들면 마이크 켜고 말로 불러줘도 됩니다
② 선택

가치관 카드 — 핵심 가치 3개

내가 일과 삶에서 중요하게 여기는 '핵심 가치 3개'를 찾습니다. 앞으로 선택의 기준이 됩니다.

📋 붙여넣을 프롬프트

나는 (나이)대이고, ( 내 상황·고민 )이야. 내가 보람이나 만족을 느꼈던 순간을 2~3가지 말할게: ( 예: 사람을 도울 때, 내 시간을 자유롭게 쓸 때 ) 이걸 보고 내 핵심 가치 3개를 뽑고, 각 가치를 한 문장으로 쉽게 설명해줘.

  • 핵심 가치 3개는 직업·목표를 고를 때 나만의 잣대가 됩니다
  • '이 가치에 맞는 일 예시도 알려줘'를 덧붙이면 더 구체적
③ 선택

인생곡선 — 굴곡에서 찾는 의미

살아온 굴곡을 그려, '내가 언제 힘이 났는지'와 그 안의 의미를 찾습니다.

📋 붙여넣을 프롬프트

내 인생의 중요한 순간을 시간 순서로 말할게. ( 예: 20대 취업 좋았음 / 40대 폐업 힘들었음 / 지금 새 출발 준비 ) 각 시기에 내가 무엇을 배웠는지, 그리고 그 경험이 지금 나에게 어떤 강점이 됐는지 따뜻하게 정리해줘.

  • 힘들었던 시기도 '거기서 뭘 배웠나'로 바꾸면 나의 자산이 됩니다
  • 종이에 가로선을 긋고 위/아래로 점을 찍으며 같이 그려보기
④ 다음 시간과 연결

강점–직업 매칭 — 어울리는 일 후보

내 강점에 어울리는 '직업·일자리 후보'를 넓게 받아봅니다. 정답이 아니라 '후보 넓히기'가 목적입니다.

📋 붙여넣을 프롬프트

내 강점은 ( 강점 3가지 )이야. 나는 (나이)대이고 ( 재취업 / 창업 / 자유롭게 ) 쪽을 생각 중이야. 이 강점을 살릴 수 있는 직업이나 일 5가지를 추천하고, 각각 어떤 점이 내 강점과 맞는지 한 줄씩 알려줘. 표로 보여줘.

  • 처음 듣는 직업이 나오면 '그건 무슨 일이야?'라고 되묻기
  • 끌리는 것 2개에 별표 → 다음 시간(2회차) 시장조사 대상이 됩니다
⑤ 선택

이키가이 4원 — 네 가지의 교차점

좋아함·잘함·돈됨·세상필요 — 네 가지가 겹치는 '내 일'을 찾습니다. ('이키가이' = 삶의 보람)

📋 붙여넣을 프롬프트

나에 대해 4가지를 말할게. ① 좋아하는 것: ( ) ② 잘하는 것: ( ) ③ 돈이 될 만한 것: ( ) ④ 세상에 필요한 것: ( ) 이 넷이 겹치는 지점에서 내가 도전해볼 일 3가지를 제안하고 이유도 설명해줘.

  • 네 칸을 다 못 채워도 됩니다 — 아는 것만 적어도 OK
  • '가장 현실적인 것부터 알려줘'를 덧붙이면 우선순위까지
⑥ 오늘의 최종 결과물 · 꼭 해보세요

나 사용설명서 — 나를 한 장으로

앞에서 나온 결과를 모아 '나를 소개하는 한 장'으로 정리합니다.

📋 붙여넣을 프롬프트

지금까지 나온 내 강점, 핵심 가치, 어울리는 일을 모아서 '나 사용설명서'를 만들어줘. 항목은 이렇게: ① 나의 강점 ② 중요히 여기는 것 ③ 함께 일할 때 좋은 점 ④ 배려할 점 누가 봐도 쉽게, 따뜻한 말투로 한 장 분량으로 정리해줘.

꼭 지키세요 — 같은 대화창에서 이어서
  • ①번 강점을 뽑았던 그 대화창에서 이어서 넣으세요.
  • 새 창을 열면 AI가 앞에서 한 이야기를 기억하지 못합니다.
  • 완성되면 캡처해 저장 — 면접·상담·자기소개에 바로 활용
  • 가족·지인에게 보여주고 '나 이런 것 같아?' 물어보기
  • 이후 최종 포트폴리오의 표지가 됩니다
5

이미지로 나를 담다

사진 실습입니다. 잘 나올 필요 없어요 — 재미로 해보는 것이 목적입니다.

사진 실습 전 꼭 지킬 것
  • 본인 얼굴 사진만 사용하세요. 남의 사진·유명인 사진은 안 됩니다(초상권).
  • 과한 보정은 피하세요 — 이력서 사진은 실제 나와 너무 달라지면 안 됩니다.
  • 무료 이미지 생성은 하루 한도가 있어요. 안 되면 다음 시간에 이어서 합니다.

① 이력서·증명 사진 만들기

준비물: 내 얼굴 사진 1장  |  도구: ChatGPT(무료) 또는 제미나이

  • 사진 올리기채팅창 아래 '＋'(사진 첨부)로 내 얼굴 사진 1장 올리기
  • 프롬프트 붙여넣기아래 문장을 복사해 붙여넣고 보내기
  • 마음에 안 들면 다시'더 밝게 / 배경 흰색으로' 하고 다시 요청
  • 저장마음에 드는 컷 저장 → 이력서·구직등록에 사용
📋 붙여넣을 프롬프트

이 얼굴 사진을 바탕으로, 단정한 정장 차림의 증명사진으로 만들어줘. 배경은 밝은 회색, 비율은 3:4, 표정은 온화하게. 실제 내 얼굴 특징은 그대로 유지해줘.

🎯 기대 결과: 흰/회색 배경의 단정한 증명사진 1장 — 이력서·구직등록에 바로 사용 가능

② 전신 프로필 사진 만들기

면접·온라인 프로필용 전신 사진도 만들 수 있어요. 여러 컨셉을 재미로!

📋 붙여넣을 프롬프트

이 사진을 바탕으로, ( 깔끔한 정장 / 단정한 캐주얼 ) 차림의 전신 프로필 사진을 만들어줘. 배경은 ( 밝은 사무실 / 깔끔한 스튜디오 ), 자신감 있고 밝은 분위기로. 얼굴 특징은 그대로.

  • '배경을 사무실로 / 야외로' 등 바꿔서 여러 장 만들어 보기
  • 가장 자신 있어 보이는 컷을 저장

③ 🎨 '제2인생의 나' 이미지 1컷

내 얼굴 사진 없이도 됩니다. 새로 출발하는 내 모습을 상상해서 그려봅니다.

📋 이렇게 부탁해 보세요

50대 (나 같은 사람)이, ( 새로 도전하고 싶은 모습: 예 - 밝은 카페에서 손님을 맞는 모습 ) 을 하고 있는 그림을 그려줘. 분위기는 밝고 따뜻하고 자신감 있게, 실사풍으로.

  • 마음에 안 들면 '더 밝게', '배경을 바꿔서' 하고 얼마든지 다시 요청하세요
  • 잘 나온 그림은 저장 → 나만의 '제2인생 명함' 느낌. 목표를 눈으로 보면 힘이 납니다
  • 정답도, 잘 그릴 필요도 없어요. 웃으며 해보는 것 자체가 목적입니다 😊

④ 나의 이야기로 '그림책' 만들기

내 인생 이야기를 짧은 그림책으로! 손주 선물로도 좋아요.

  • 이야기 한 조각 넣기아래 프롬프트에 내 이야기를 넣어요
  • 이야기 + 장면 설명 받기AI가 짧은 이야기와 장면 설명을 만들어 줍니다
  • 삽화 요청'각 장면을 그림으로 그려줘'라고 이어서 부탁
  • 저장글+그림을 캡처해 나만의 그림책으로
📋 붙여넣을 프롬프트

나는 (나이)대이고, ( 내 인생의 한 장면: 예-고향에서 자란 이야기 )을 어린이 그림책처럼 4장면의 짧은 이야기로 만들어줘. 따뜻하고 쉬운 말로, 각 장면마다 그림 설명도 붙여줘.

🎯 기대 결과: 4장면짜리 나만의 그림책 초안 — 자서전·손주 선물·자기소개 자료로 확장 가능
시간이 부족하면 글만 먼저 만들고 그림은 집에서 이어서 해도 됩니다.
